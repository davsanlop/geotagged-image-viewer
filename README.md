Bienvenid@ al repositorio del visor de imágenes geoetiquetadas. El objetivo de este proyecto es poder prestar soporte al equipo de delineación mediante un visor web ligero y sencillo de usar donde puedan
comprobarse las imágenes tomadas en campo para verificar la existencia de afecciones o elementos del suelo en el estudio de tramos subterráneos.

El uso es muy intuitivo. Se muestran las imágenes ordenadas por directorios de proyectos, pudiendo filtrar para solo enseñar las imágenes deseadas, y al pulsar en una imagen se muestra en tamaño completo sobre el mapa, con opción de descargarla.
También se puede explorar directamente sobre el mapa, y se puede elegir entre un mapa base topográfico y una imagen de satélite. Es posible también descargar en un archivo comprimido todas las imágenes asignadas a un
directorio de proyecto concreto.

Las imágenes muestran los metadatos correspondientes a fecha de creación, nombre del archivo, proyecto al que pertenecen, orientación con azimut y coordenadas. Pulsando sobre la imagen dentro del visor se puede ampliar para verse en tamaño original.
